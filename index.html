Lembretes e instalação

Como instalar como app no Chrome

Se o botão “📲 Instalar app” aparecer no topo, toque nele. Se não, use ⋮ → “Instalar app” ou “Adicionar à tela inicial”. Para instalação completa e uso sem internet, hospede o pacote PWA (arquivo LEIA-ME).

Os prazos são médias. Ajuste conforme clima, vaso e solo: se a terra ainda está úmida a 2 cm de profundidade, espere para regar. Os dados ficam salvos neste navegador.
